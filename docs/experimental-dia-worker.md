# Isolated experimental DIA PAPER worker

This optional worker uses a separate learner directory, explicit DIA-only configuration and an existing operator-approved frozen model. It does not alter the original learner universe, transfer legacy exit ownership, or grant live execution.

The forward configuration must name the original learner declaration database as well as the shared research registry. Both sources must permit a feature/training window. Protected declarations are immutable; a missing declaration store fails closed.

The exclusive entry policy refuses another active learner entry promotion and counts every non-grandfathered account position against the single-new-position cap. Grandfathered holdings remain in aggregate portfolio risk and retain their existing exit owner. Position value and entry risk are capped at 500 and 25 basis points respectively, with any tighter existing controls retained. The existing 100-basis-point stop and 30-minute horizon remain.

Operational daily risk collection covers the pilot and inherited symbols with a configuration-scoped ingestion cursor. This data is operational risk input, not permission to fit on protected dates. Missing history, liquidity, correlation or fresh forecast evidence must reject an entry.

Before enabling the new limited-principal task, back up configuration and a consistent operational database without copying credential files. Record the approved model and experimental authority, audit suspension of the prior learner entry promotion, and preserve the original forecast and exit tasks. Rollback stops only the new worker and demotes its entry authority; preserve receipts and orders/deadlines, and never rewind an active account database. Restoring another entry promotion requires its normal supported transition and intact binding.

Validation is synthetic until real scheduled receipts show a forecast, eligible intent/fill or explicit veto, independent protection/deadline handling and a recorded outcome. Sparse historical diagnostics are not profitability evidence. No automatic challenger promotion is enabled.
