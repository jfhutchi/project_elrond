# QuantBot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic, restart-safe Adaptive Momentum research and Alpaca paper-trading system that can enter a real qualification window without permitting accidental live trading.

**Architecture:** A Python 3.11 modular monolith keeps strategy, risk, broker, market-data, storage, operations, and reporting behind typed boundaries. SQLite/WAL is the durable audit/state store; async HTTP/WebSocket transports integrate Alpaca; historical backtesting reuses strategy and risk rules but uses an explicitly separate local fill model.

**Tech Stack:** Python 3.11, uv, Pydantic 2/pydantic-settings, httpx, websockets, SQLAlchemy 2/Alembic, pandas/numpy, Typer, structlog, prometheus-client, pytest/pytest-asyncio/Hypothesis/respx, Ruff, mypy.

---

## File Map

- `src/quantbot/config.py`: environment loading, secret types, and fail-closed PAPER/LIVE guards.
- `src/quantbot/domain/`: immutable Decimal/UTC models, enums, IDs, lifecycle transitions, and errors.
- `src/quantbot/storage/`: SQLAlchemy schema, migrations, repositories, transactions, and single-writer lock.
- `src/quantbot/strategy/`: indicators, Adaptive Momentum rules, version identity, and signal output.
- `src/quantbot/risk/`: drawdown policy, portfolio constraints, readiness gates, and sizing.
- `src/quantbot/brokers/`: neutral adapter, Alpaca implementation/stream, and explicit Tradier/IBKR extension points.
- `src/quantbot/market_data/`: neutral provider, validation/freshness, Alpaca history/stream, and cache.
- `src/quantbot/execution/`: coordinator, event application, timeout recovery, and reconciliation.
- `src/quantbot/backtest/`: historical fill model, engine, benchmarks, metrics, and experiment manifest.
- `src/quantbot/operations/`: cycle runner, daemon scheduling, health, kill switch, qualification, and metrics.
- `src/quantbot/reporting/`: performance calculations and weekly/status rendering.
- `src/quantbot/cli.py`: safe operator commands.
- `tests/`: unit, contract, integration, fault-injection, anti-look-ahead, and opt-in paper smoke tests.
