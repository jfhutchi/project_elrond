Fetch the latest bars

Reads the market-data provider and durably caches completed bars. Submits no order, cancels nothing and moves no position, and a bar already stored is never rewritten — a repeated sync cannot revise history.

Worth having here because MARKET_DATA_STALE halts a trading cycle, and the fix is almost always “fetch the bars”. An operator who can see the staleness should be able to address it from the same page rather than from a terminal.
